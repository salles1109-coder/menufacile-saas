Formas de recebimento

Estas regras são compartilhadas pelos menus de restaurante e produtos. A taxa aplicada no pedido vem sempre desta configuração.

Permitir entregaExibe endereço, consulta de CEP e frete no checkout.
Permitir retirada no localO cliente pode retirar diretamente no estabelecimento.

Como deseja calcular a entrega?

Escolha uma opção. O painel mostra somente os campos necessários para esse modelo.

Taxa fixa da entrega

Este campo aparece apenas quando a taxa fixa for usada como cálculo principal ou como alternativa.

Use R$ 0,00 caso a entrega fixa seja gratuita.

Regras gerais da entrega

Estas regras são aplicadas depois do cálculo escolhido.

O pedido mínimo controla quando a entrega pode ser escolhida. O frete grátis substitui o valor calculado quando o subtotal atingir o limite.
Use R$ 0,00 para não exigir valor mínimo.
Use R$ 0,00 para não oferecer frete grátis automaticamente.

Prazo da entrega com taxa fixa

Informe em uma unidade fácil de entender. O sistema salva internamente em minutos.

Para cidades cadastradas, use o prazo de cada cidade. Para cálculo por distância, use o prazo da seção de distância.

Retirada no local

Tempo necessário para separar e preparar o pedido antes de o cliente buscar.

Exemplo: 30 minutos significa que o pedido ficará pronto para retirada em aproximadamente 30 minutos.

Cálculo por distância
